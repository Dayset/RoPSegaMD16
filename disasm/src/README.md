## As built (2026-11-09, continuation session) — READ THIS

`tools/split_disasm.py --emit` now generates this tree from the
user's ROM + the #011 function map:

- `main.s` — include chain over 16 region files (`r_XXXXXX.s`),
  in address order, covering 0x000000–0x100000 contiguously.
- Region files mix, at block granularity: GNU-as code (Capstone
  decode of #011 function bodies, converted to GAS syntax) and
  `.incbin "data/XXXXXX.bin"` slices for everything else.
- `data/*.bin` are verbatim ROM slices — **git-ignored (`*.bin`),
  regenerated by `--emit` from `rop-original.gen`, never
  committed** (same rule as `disasm/rop.s`).
- `manifest.json` (git-ignored, regenerated) maps every emitted
  instruction's ROM offset to (file, line, text, bytes) for
  `tools/fixup_src.py`.
- Fidelity mechanism: each code block is round-trip assembled
  standalone at its true VMA during `--emit`; any instruction
  whose GAS encoding differs from the ROM bytes (GAS opcode
  normalisation such as `cmp #imm` → CMPI, embedded data inside
  function bodies, block-end truncations) is emitted as `.dc.b`
  of the original bytes instead. About 14.5K of 54K instructions
  took the fallback in the first verified build — the tree is
  byte-exact, and the fallback count is the honest price of
  GAS/Capstone impedance, recorded here rather than hidden.
- Verified 2026-11-09: `tools/build.sh` → 1,048,576 bytes;
  `tools/verify_rebuild.py` PASS; `cmp` vs the original ROM:
  **fully byte-identical, checksums included** (milestone M5).
