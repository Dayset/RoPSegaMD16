Record layout (verified against the raw bytes):
  item record  = 14 bytes: [10-byte name, NUL-padded][A][B][C][grp]
  header record = 12 bytes: [10-byte name, NUL-padded][A][grp]
  (headers are the menu titles: MAIN, FIGHT, MOOD, PARTY, TACTIC, BUY, INVEN, USE)
grp = menu/group id: 1=main/shop, 2=party disciplines, 4=mood/tactic headers,
  5=inven header, 6=combat/party headers, 8=mood/tactic/shop items.
C reads as the item's verb/action code for the main menu (Party=0x64, Search=0x13,
Map=0x11, Camp=0x1C) and as a 0-based index for PARTY (0-5) and TACTIC (8-11);
the exact mapping of A/B/C to the $D28E command switch is NOT yet proven - #021.
