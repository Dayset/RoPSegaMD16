$D28E command switch (at $D740, d0 = command byte from -$4(a6)) - from #020
Command values and the routine each case calls. The verb-code -> menu-name
mapping is partial: 37 (0x25) = confirm (written by $12FE8 on a face-button
press); 10 = the $FF0128 path ($D328 writes 10 literally); 40 (0x28) is
special-cased at $D43E. The other codes are written into the command slot by
paths not yet fully traced - see docs/architecture.md.

  cmd    case addr  callee            notes
  0      $D6B0      (fallthrough)     no-op / idle
  10     $D4AC      $1EEEE            $FF0128 path (loaded-game branch)
  20     $D4F2      $1E3B0            message-queue push (enqueue)
  21     $D552      $1F296            big verb executor (0x1F296-0x2077A, ~3.6KB)
  22     $D55C      $207D8            (untraced)
  23     $D566      $1E5A0            (untraced)

  -> $20A36(1, 0) calls. $FF00AC / $FF02B2 / $FF02DB checks precede them.
