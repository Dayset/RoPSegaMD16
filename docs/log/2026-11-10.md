## #012: jump-table dispatch resolved
- Cause: vasm measures a `$addr(pc,Xn)` operand from the instruction's own address, not the extension word, so the numeric target encoded the wrong displacement (4EFB0070 instead of 4EFB0000 at 0x01306E).
- Fix: write the displacement explicitly, `jmp *+N(pc,Xn)` where N = d8 + 2 and d8 is read from the ROM's extension word. Tested: `jmp *+2(pc,d0.w)` at 0x1306E encodes 4EFB0000.
- Result: gate PASS byte-identical; 0 raw dc.w fallbacks; 54,182 mnemonic instructions.
