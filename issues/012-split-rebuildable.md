# Issue #012 — Split rebuildable asm: code vs incbin data

**Epic 1**  
**Milestone:** M2  
**Status:** open

## Goal
Turn the disassembly into a rebuildable source tree: labelled code in
`.s` files, data as `incbin` of verified ROM slices.

## Acceptance
- [ ] `disasm/src/` layout decided (entry, handlers, game code, data slices)
- [ ] Data regions are `incbin` ranges copied verbatim from the ROM, with
      start/end addresses recorded — never hand-typed bytes
- [ ] Labels for every vector-reached routine found so far
- [ ] No file in `disasm/src/` is generated by the linear sweep
